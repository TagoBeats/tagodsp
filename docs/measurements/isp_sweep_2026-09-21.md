# ISP-Sweep: Inter-Sample-Peaks nach dem Clipping

Erzeugt von `examples/isp_sweep.py`, sr 44100 Hz, 1 s pro Signal, 324 Kombinationen.
True Peak gemessen mit 16x Oversampling nach BS.1770-4 (`analysis/true_peak.py`).

Zwei verschiedene Zahlen, beide noetig:

- **Ueberschuss** ist True Peak minus Sample-Peak. Er sagt, wie viel ein Sample-Peak-Meter dem Nutzer verschweigt.
- **Ueber Decke** ist True Peak minus der nominalen Decke der Kurve (Threshold bei `hard`, 0 dBFS bei `fl` und `tanh`). Das ist die Zahl, die das Produktversprechen tragen muss, denn sie sagt, ob die Datei die Plattform-Pruefung besteht.

## Antwort auf die Ausgangsfrage

- Groesster Ueberschuss ueber dem Sample-Peak: **+5.82 dB** (noise, Kurve hard, Threshold 0.50, Drive +24 dB, Oversampling 1x)
- Groesste Ueberschreitung der Decke: **+5.82 dB** (noise, Kurve hard, Threshold 0.50, Drive +24 dB, Oversampling 1x)
- Kombinationen mit Ueberschuss ueber 0.1 dB: **222 von 324**
- Kombinationen mit Deckenueberschreitung ueber 0.1 dB: **296 von 324**
